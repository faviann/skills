# Index frozen review inputs per gate

To reduce reviewer semantic ingestion without weakening frozen authority, `work-on` dispatches each review gate from one immutable **Review index** whose identity binds the exact comparison endpoints and complete frozen input universe. Each axis starts with only the material appropriate to its obligation but retains unrestricted verified widening within that pinned universe; changed-path discovery and diffs derive from the pinned Git trees rather than a mandatory rendered diff. The input-only index carries no review-chain state and changes review-context delivery and starting sets only: on-demand availability does not satisfy an inspection obligation when that material is needed to discharge the axis, while existing cumulative coverage and final fresh cumulative-confirmation requirements remain unchanged.
